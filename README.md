# Учебный эмулятор постамата

### Типы событий

| Код | Значение |
| --- | --- |
| `CODE_ACCEPTED` | Постамат принял код выдачи. |
| `CODE_REJECTED` | Постамат отклонил код выдачи. |
| `PICKUP_CANCELLED` | Клиент отменил выдачу до отправки команды открытия. |
| `OPEN_COMMAND_SENT` | Постамат отправил команду открыть ячейку. |
| `OPEN_COMMAND_FAILED` | Постамат не смог отправить команду открытия. |
| `DOOR_OPEN_CONFIRMED` | Датчик подтвердил открытие дверцы. |
| `DOOR_OPEN_FAILED` | Постамат зафиксировал, что после команды дверца осталась закрытой. |
| `OPEN_CONFIRMATION_TIMEOUT` | Время ожидания истекло. Подтверждение открытия не пришло, положение дверцы неизвестно. |
| `PARCEL_REMOVED` | Датчик зафиксировал извлечение посылки. |
| `DOOR_LEFT_OPEN` | Дверца оставалась открытой дольше допустимого времени. Позже в той же попытке может появиться запись о закрытии. |
| `DOOR_CLOSED_CONFIRMED` | Датчик подтвердил закрытие дверцы. |
