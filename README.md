# Учебный эмулятор постамата

Каждый запрос `GET /logs` создаёт новый учебный журнал из 40–50 строк. Заказы вымышлены. Сервер использует стандартную библиотеку Python 3.10 или новее.

## Запуск в GitHub Codespaces

В каждой строке четыре поля. Это **дата и время, номер заказа, номер попытки и тип события**. Весь журнал относится к одной дате. Дата берётся по UTC, время событий учебное. Строки перемешаны, поэтому порядок нужно восстанавливать по времени.

| Событие                     | Значение                                 |
| --------------------------- | ---------------------------------------- |
| `CODE_ACCEPTED`             | Постамат принял код выдачи               |
| `OPEN_COMMAND_SENT`         | Постамат отправил команду открыть ячейку |
| `DOOR_OPEN_CONFIRMED`       | Датчик подтвердил открытие               |
| `OPEN_CONFIRMATION_TIMEOUT` | Истекло время ожидания подтверждения     |

Попытка может остаться без итоговой записи. Номер попытки относится к конкретному заказу. Сервер хранит счётчик выданных журналов в локальном файле `.postamat-state.sqlite3`. Пока используется эта база, номера заказов различаются между журналами даже после перезапуска сервера. Новый Codespace создаст собственный счётчик.

## Локальный запуск

В Windows из папки проекта выполните `py server.py`, на Linux и macOS — `python3 server.py`. Журнал доступен по адресу `http://localhost:8000/logs`.
